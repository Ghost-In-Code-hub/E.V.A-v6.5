# E.V.A. — Enhanced Virtual Assistant

**Intelligence at your command.**

E.V.A. is an AI-powered desktop voice assistant inspired by futuristic assistants like JARVIS. It aims to combine natural voice conversations, intelligent AI responses, hands-free PC control, and a futuristic sci-fi interface into one unified experience.

## 🚀 Easy Setup — One File to Get Started

**No complicated manual installation required!**

E.V.A. is designed to make installation simple. Just download or clone the repository and run the provided **setup file**.

### Installation

1. Download or clone this repository.
2. Open the project folder.
3. Double-click the setup file (for example, `setup.bat`).
4. Follow the on-screen instructions.
5. Once setup is complete, launch E.V.A. using the provided startup file.

The setup script is intended to automate dependency installation and project configuration, reducing the need to enter commands manually.

**Note:** API keys for supported AI and voice services may still need to be configured. Actual installation behavior depends on what the setup script implements.

## ✨ Key Features

- 🎙️ **Natural Voice Interaction** — Communicate with E.V.A. using your voice.
- 🧠 **AI-Powered Intelligence** — Generate responses using integrated AI models.
- ⚡ **Real-Time Voice Processing** — Integrates LiveKit, Deepgram, and Cartesia.
- 💻 **PC Automation** — Intended support for opening applications and performing computer tasks.
- 🌐 **Web Assistance** — Designed to assist with browser-based searches and online workflows.
- 🎨 **Futuristic Interface** — A sci-fi-inspired interface with an animated energy core.
- 🔊 **Hands-Free Experience** — Aiming for responsive, natural voice-controlled interaction.
- 🛠️ **Simplified Installation** — A setup script designed to automate installation.

## 🔐 API Keys and Security

E.V.A. may require API keys for its AI and voice services.

- Store credentials in a local `.env` file.
- Never upload API keys or passwords to GitHub.
- Follow the setup instructions if API configuration is required.
